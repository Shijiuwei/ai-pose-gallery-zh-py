# 姿势参考·上半身

人体姿势参考库（上半身）：400 张 900×1200 白模姿势图，覆盖 80 种姿势、5 种视角（正面/斜侧/侧面/俯视/仰视）。图片位于仓库 `img/` 目录，`图片` 列为相对本技能根目录的路径，请保留仓库目录结构使用。

## 何时使用

用户需要角色摆出特定动作/姿势、需要多角度动作参考、或描述的姿势难以用文字控制时。

## 用法

1. 从下方「姿势目录」按分类和姿势名找到最贴近用户描述的姿势；拿不准时给用户 2-3 个候选。
2. 读 `references/catalog.csv`，按 `姿势名称` + `角度` 取 `图片` 列（**相对本技能根目录的路径**，如 `../../img/xxx.png`）；视角优先匹配用户镜头，默认正面。
3. 把该图作为**姿势/构图参考图**传给生图或生视频模型（ControlNet / 姿势参考 / 参考图），提示词注明「仅参考姿势，不参考服装、发型、画风」。
4. 同一姿势需要多角度时，同时取该姿势的多个角度；多人互动时为每个角色各取一个姿势。

## 注意

- 参考图仅用于姿势骨架，生成内容须遵守所用平台的内容规范。
- 本技能含成人向姿势（18+），请勿用于生成涉及未成年人或违法内容。
- 图片著作权归原作者ギア（ai-pose-gallery.pages.dev），中文整理 anhao/ai-pose-gallery-zh；仅供个人创作参考，不得商用。
